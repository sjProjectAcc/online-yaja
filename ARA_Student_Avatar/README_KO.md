# ARA 학생 아바타 3D 모델 · 로우폴리 GLB

온라인 자습실에 사용할 **실제 3D 메시**입니다. 이전 디자인 시트 이미지를 기초로 만들었지만 완전히 동일한 정밀 복제는 아닌, 저폴리곤 스타일의 독립 모델입니다.

## 제공한 3D 파일

- `core.glb`: 얼굴, 머리카락, 목, 손, 운동화. 다른 파츠와 조합하는 공통 베이스
- `top_shirt.glb`: 기본 흰색 셔츠
- `top_hoodie.glb`: 셔츠 카라가 살짝 보이는 회색 후드티 착장
- `top_blazer.glb`: 흰 셔츠+넥타이를 안에 입은 감색 교복 재킷(체크 파이핑, 금색 단추, 파란색 교표)
- `top_track_jacket.glb`: 체육복 긴팔 집업, 왼쪽 가슴 `ara` 로고(하늘색)
- `top_sports_tshirt.glb`: 체육복 반팔, 하늘색 `ara` 로고
- `bottom_uniform.glb`: 회색 교복 긴바지
- `bottom_track.glb`: 체육복 긴바지
- `bottom_shorts.glb`: 체육복 반바지 + 드러나는 다리

각 옷에는 원본 사진의 주요 특징을 반영했습니다. **체육복의 평행 줄 두 개는 하늘색 1개 + 흰색 1개**입니다. `ara` 로고는 하늘색입니다.

## 확인용 완성형 프리셋

`preset_school_uniform.glb` / `preset_shirt_uniform.glb` / `preset_hoodie_uniform.glb` / `preset_sports_winter.glb` / `preset_sports_summer.glb`

## 조립 기준

- 오른손 좌표계, **Y가 위**, +Z가 캐릭터의 전면, 미터 단위, 바닥 원점 Y=0.
- 모델 높이 약 **1.44m** (귀여운 SD 비율을 적용한 가상의 인체 스케일).
- `core.glb` 1개 + **상의 1개** + **하의 1개**를 모두 좌표 (0,0,0), 회전 0, 배율 1로 로드하면 자동 정렬됩니다.
- 재킷과 후드티 자산에는 셔츠가 보이는 부분을 미리 포함했습니다. 상의끼리 겹쳐 로드하면 겹침이 생기므로 상의 한 개만 선택합니다.
- 각 파일은 GLB 자체에 정점 색상이 포함되어 있으며 외부 이미지 텍스처를 요구하지 않습니다.
- GLB는 Blender, Three.js GLTFLoader, React Three Fiber useGLTF로 불러올 수 있습니다.

## 애니메이션 관련 주의

**현재 자산은 A-포즈의 정적 메시이며 본/스킨 리깅 및 걷기·앉기 애니메이션은 포함하지 않습니다.** 머리·팔·다리·의복이 이름별로 분리된 노드로 제공되어 추후 리깅 작업을 이어갈 수 있습니다. 의자에 앉히려면 Blender 등에서 리깅/착석 애니메이션과 좌판 높이 보정이 추가로 필요합니다. 단순히 Claude Code에서 GLB를 로드한다고 자동으로 관절이 굽거나 앉지 않습니다.

## 다중접속 성능

모든 완성형 모델은 약 **2,754~3,611개의 삼각형**으로 구성되며, 3D 의상 디테일을 위한 일부 파츠는 각각 독립 메시입니다. 실제 동시 접속 성능은 화면에 표시되는 아바타 수, 렌더러, 기기 사양 및 텍스처/애니메이션/네트워크 구현에 따라 달라집니다. 많은 아바타를 화면에 띄울 때는 의상별 지오메트리/재질 병합, 리소스 캐싱, 거리별 LOD, 화면 밖 모델 렌더링 생략 등을 적용하세요.

`model_manifest.json`에 각 파일의 실제 삼각형 수·메시 그룹 수와 조립 목록을 기록했습니다.

## 경량화 파일 (온라인 자습실에 권장)

`optimized/` 폴더에 동일한 모양의 모델을 각각 **메시 1개로 병합한 GLB**로 넣었습니다.

- 모델을 정적으로 표시할 때 `optimized/core.glb` + `optimized/top_*.glb` 1개 + `optimized/bottom_*.glb` 1개를 함께 로드하면 일반적으로 **3개의 렌더링 메시**로 화면에 표시됩니다.
- 의상 전체가 확정돼 바꿀 필요가 없을 때 `optimized/preset_*.glb` 1개를 사용하면 메시 한 개입니다.
- 이 경량 버전은 리깅 전 단계의 정적 모델이므로, 캐릭터 관절을 움직이려면 본과 스킨 웨이트를 먼저 추가해야 합니다. 리깅 편의를 우선한다면 부위별 노드가 구분된 최상위 `*.glb` 사용을 권합니다.
